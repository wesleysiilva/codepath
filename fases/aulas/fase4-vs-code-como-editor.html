O conceito essencial

Instalação e extensão Python. Sintaxe highlight, autocomplete, terminal integrado. Por que um bom editor importa. Alternativa no browser: Google Colab para quem não quer instalar nada.

Observe a ideia em contextoO VS Code é um editor; a extensão Python adiciona realce, execução, depuração e integração com interpretadores. O terminal integrado executa comandos no projeto. Google Colab oferece notebooks no navegador, útil quando não se pode instalar localmente.

Como aplicar

O VS Code é um editor; a extensão Python adiciona realce, execução, depuração e integração com interpretadores. O terminal integrado executa comandos no projeto. Google Colab oferece notebooks no navegador, útil quando não se pode instalar localmente.

Ao analisar um caso, identifique primeiro a entrada e o resultado esperado. Depois verifique as condições e os limites descritos acima; essa sequência ajuda a distinguir a regra do exemplo e a transferi-la para outras situações.

Prática e entregável

Configure um arquivo .py no VS Code, escolha o interpretador e execute-o pelo terminal integrado. Inclua captura com extensão ativa e compare uma vantagem e uma limitação do Colab.

🎯
Critério de conclusãoEntregue o artefato solicitado com um exemplo testado, explique a decisão tomada e registre ao menos um limite ou caso de borda.
