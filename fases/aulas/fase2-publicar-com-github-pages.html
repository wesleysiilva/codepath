O conceito essencial

Criar um repositório no GitHub (primeiro contato com Git), fazer upload dos arquivos, e publicar o glossário com uma URL pública. Você sai com um link para compartilhar.

💡
Observe a ideia em contextoUm repositório guarda arquivos e histórico de versões; Git registra alterações em commits. GitHub Pages publica arquivos estáticos do repositório em uma URL. Não coloque senhas, tokens ou dados privados em um site público.

Como aplicar

Um repositório guarda arquivos e histórico de versões; Git registra alterações em commits. GitHub Pages publica arquivos estáticos do repositório em uma URL. Não coloque senhas, tokens ou dados privados em um site público.

Ao analisar um caso, identifique primeiro a entrada e o resultado esperado. Depois verifique as condições e os limites descritos acima; essa sequência ajuda a distinguir a regra do exemplo e a transferi-la para outras situações.

Prática e entregável

Publique o glossário em um repositório próprio com index.html e CSS. Configure Pages, abra a URL em janela anônima e entregue a URL, o commit publicado e uma verificação de que links e imagens carregam.

🎯
Critério de conclusãoEntregue o artefato solicitado com um exemplo testado, explique a decisão tomada e registre ao menos um limite ou caso de borda.
