O conceito essencial

O protocolo da web. Request e response. Métodos: GET (buscar), POST (enviar), PUT (atualizar), DELETE (apagar). Códigos de status: 200 OK, 404 Not Found, 500 Server Error.

💡
Observe a ideia em contextoUma requisição GET /produtos pode receber 200 e JSON; POST /pedidos envia dados para criar um pedido. 404 indica recurso não encontrado e 500 falha no servidor. HTTPS protege o tráfego HTTP com TLS, mas não garante que o site seja honesto.

Como aplicar

Uma requisição GET /produtos pode receber 200 e JSON; POST /pedidos envia dados para criar um pedido. 404 indica recurso não encontrado e 500 falha no servidor. HTTPS protege o tráfego HTTP com TLS, mas não garante que o site seja honesto.

Ao analisar um caso, identifique primeiro a entrada e o resultado esperado. Depois verifique as condições e os limites descritos acima; essa sequência ajuda a distinguir a regra do exemplo e a transferi-la para outras situações.

Prática e entregável

No DevTools ou em uma API de teste, registre método, URL, status e corpo de três requisições. Explique por que GET é adequado para consultar e POST para enviar uma nova inscrição.

🎯
Critério de conclusãoEntregue o artefato solicitado com um exemplo testado, explique a decisão tomada e registre ao menos um limite ou caso de borda.
