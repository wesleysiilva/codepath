Perfil GitHub público

Foto, bio, pinned repositories. O GitHub como currículo técnico — um perfil ativo diz mais sobre um desenvolvedor do que qualquer certificado.

⏱ ~15 min
📶 Iniciante
12 de 16 aulas

O conceito essencial

Foto, bio, pinned repositories. O GitHub como currículo técnico — um perfil ativo diz mais sobre um desenvolvedor do que qualquer certificado.

💡
Observe a ideia em contextoUm perfil público pode destacar repositórios relevantes, README de perfil e bio concisa. Commits não contam a história toda; pinne projetos concluídos e mantenha instruções, licença e demonstrações atualizadas para que visitantes entendam seu trabalho.

Como aplicar

Um perfil público pode destacar repositórios relevantes, README de perfil e bio concisa. Commits não contam a história toda; pinne projetos concluídos e mantenha instruções, licença e demonstrações atualizadas para que visitantes entendam seu trabalho.

Ao analisar um caso, identifique primeiro a entrada e o resultado esperado. Depois verifique as condições e os limites descritos acima; essa sequência ajuda a distinguir a regra do exemplo e a transferi-la para outras situações.

Prática e entregável

Revise bio, foto (opcional), README do perfil e seis repositórios destacados. Remova segredos e dados pessoais desnecessários; teste links e escreva em cada projeto qual habilidade ele demonstra.

🎯
Critério de conclusãoEntregue o artefato solicitado com um exemplo testado, explique a decisão tomada e registre ao menos um limite ou caso de borda.
