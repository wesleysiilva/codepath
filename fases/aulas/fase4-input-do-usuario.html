Input do usuário

Input() sempre retorna string — a armadilha mais comum para iniciantes. Converter para int antes de operar matematicamente. O programa passa a ser interativo.

⏱ ~15 min
📶 Iniciante
8 de 24 aulas

O conceito essencial

input() sempre retorna string — a armadilha mais comum para iniciantes. Converter para int antes de operar matematicamente. O programa passa a ser interativo.

💡
Observe a ideia em contexto`input()` sempre retorna str. Se o usuário digitar 12, somar o resultado com 3 não é uma operação numérica; use `int(input(...))` para inteiro ou `float(...)` para decimal e considere que texto inválido pode causar ValueError.

Como aplicar

`input()` sempre retorna str. Se o usuário digitar 12, somar o resultado com 3 não é uma operação numérica; use `int(input(...))` para inteiro ou `float(...)` para decimal e considere que texto inválido pode causar ValueError.

Ao analisar um caso, identifique primeiro a entrada e o resultado esperado. Depois verifique as condições e os limites descritos acima; essa sequência ajuda a distinguir a regra do exemplo e a transferi-la para outras situações.

Prática e entregável

Faça um programa que peça dois preços decimais, converta com float e mostre soma formatada. Teste uma entrada válida e uma inválida; escreva a mensagem que orienta a correção sem encerrar abruptamente.

🎯
Critério de conclusãoEntregue o artefato solicitado com um exemplo testado, explique a decisão tomada e registre ao menos um limite ou caso de borda.
