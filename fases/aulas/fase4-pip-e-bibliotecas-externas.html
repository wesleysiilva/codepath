pip e bibliotecas externas

Pip install e requirements.txt. PyPI como repositório central. Instalar e usar requests para fazer chamadas HTTP em Python.

⏱ ~15 min
📶 Iniciante
19 de 24 aulas

O conceito essencial

pip install e requirements.txt. PyPI como repositório central. Instalar e usar requests para fazer chamadas HTTP em Python.

💡
Observe a ideia em contextopip instala pacotes do PyPI; use `python -m pip install requests` no ambiente correto e registre dependências em requirements.txt. `requests.get(url, timeout=10)` consulta HTTP; verifique status e trate falhas de rede antes de usar a resposta.

Como aplicar

pip instala pacotes do PyPI; use `python -m pip install requests` no ambiente correto e registre dependências em requirements.txt. `requests.get(url, timeout=10)` consulta HTTP; verifique status e trate falhas de rede antes de usar a resposta.

Ao analisar um caso, identifique primeiro a entrada e o resultado esperado. Depois verifique as condições e os limites descritos acima; essa sequência ajuda a distinguir a regra do exemplo e a transferi-la para outras situações.

Prática e entregável

No venv, instale requests e consulte uma API pública com timeout. Verifique status antes de ler JSON, salve a dependência em requirements.txt e teste uma URL inválida com tratamento apropriado.
