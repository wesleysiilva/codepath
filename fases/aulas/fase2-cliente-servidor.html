Fase 2 · Web, HTTP e APIs

Cliente × Servidor

Modelo fundamental de aplicações modernas. O navegador (cliente) pede; o servidor responde. Onde o código roda: no navegador (frontend) ou no servidor (backend).

⏱ ~15 min
📶 Iniciante
8 de 18 aulas

O conceito essencial

Modelo fundamental de aplicações modernas. O navegador (cliente) pede; o servidor responde. Onde o código roda: no navegador (frontend) ou no servidor (backend).

💡
Observe a ideia em contextoO navegador é cliente: solicita HTML, imagens ou dados. O servidor recebe cada pedido, aplica regras e devolve uma resposta. JavaScript pode executar no frontend; validação de autoridade e acesso a banco normalmente ficam no backend.

Como aplicar

O navegador é cliente: solicita HTML, imagens ou dados. O servidor recebe cada pedido, aplica regras e devolve uma resposta. JavaScript pode executar no frontend; validação de autoridade e acesso a banco normalmente ficam no backend.

Ao analisar um caso, identifique primeiro a entrada e o resultado esperado. Depois verifique as condições e os limites descritos acima; essa sequência ajuda a distinguir a regra do exemplo e a transferi-la para outras situações.

Prática e entregável

Desenhe o fluxo de um formulário de login, separando o que o navegador exibe, o que envia ao servidor e o que o servidor valida. Identifique ao menos uma validação que não deve existir apenas no cliente.

🎯
Critério de conclusãoEntregue o artefato solicitado com um exemplo testado, explique a decisão tomada e registre ao menos um limite ou caso de borda.
